# 🎁 Juego de Amigo Secreto  

Este es un proyecto desarrollado en **JavaScript** como parte del **challenge de Allura**. Permite a los usuarios ingresar nombres de amigos y realizar un **sorteo aleatorio** para asignar un amigo secreto.  

## 🚀 Características  
- Agregar amigos a la lista.  
- Mostrar los nombres ingresados en pantalla.  
- Sortear un amigo secreto de manera aleatoria.  

## 🛠️ Tecnologías utilizadas  
- **HTML5**  
- **CSS3**  
- **JavaScript (DOM y lógica de programación)**
